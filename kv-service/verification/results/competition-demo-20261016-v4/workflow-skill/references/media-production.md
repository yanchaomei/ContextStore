# 图片、旁白和真实演示

## 机制插图

先从当前实现/设计中写出图意清单：必须出现的实体、箭头方向、阶段、发布条件、
失败路径与尚未实现的部分。把拟生成的图与真实结果图分开管理。

用户需要 GPT Image 2 插图时用当前环境的内置 `image_gen` 能力，按 imagegen
技能执行生成/编辑与参考图检查。工具不可用时明确缺口，不用“已生成”代替
提示词或草图；工具未返回精确模型名时仅如实记录所用工具及用户请求的模型。

可用提示词结构：

> 为技术竞赛作品说明绘制一张清晰的机制插图。项目事实：<经证据核对的实体与
> 流程>。读者要理解：<一个关键决策>。箭头语义：<方向/阶段>。必须保留的
> 边界：<已实现/规划、正常/失败>。文字保持简短，关键标签使用 <语言>。
> 不添加实验数值、性能曲线、品牌背书或源材料中不存在的组件。

逐图打开检查语义与图面；尤其核对箭头、术语、拼写、版本边界和重复/多余实体。
语义错误需要编辑或重新生成。用于 PDF/视频的导出版本也要检查。图注说明
“AI 生成的机制示意，依据 <源码/设计版本>；不代表实验结果”。

保存一份 provenance 记录：用途、提示词/编辑指令、工具回执、实际可确认的模型、
参考图及来源、原图/导出图哈希、语义检查范围、图注、引用位置。保留可编辑的
SVG/原生图作为技术结构源时，不应仅为风格替换而丢失它。

真实实验图继续由原始数据与绘图代码生成；AI 不重画统计量、曲线或截图证据。
已经生成的示意图若与最新实现冲突，应修图或标明设计状态，而非改写事实配合图。

## 分镜与真实终端

使用 [场景样例](scenes.example.json) 建立逐段计划。每段写出画面、动作、观察、
证据路径/日期、旁白、音频路径、场景时长和实际处理；精确字段可按渲染器扩展。

真实操作录制应保存：命令、输入、起止时间、退出码、完整 stdout/stderr、带相对
时间的事件流（如 asciinema cast）和原始结果文件。录制前查看屏幕与输出，避免
凭据/个人信息进入素材；保留原始事件内容和顺序。可用项目已有录制器，或当前
环境可用的终端捕获工具；不要从事后整理的文本伪造逐字出现的“实时运行”。

视频可用回放和机制图组成。等待压缩、裁切视窗、字幕、省略无关输出等处理应
有可追溯编辑记录并在适当位置标注。原始捕获另附；压缩时保留完整关键输出、
发生顺序及真实等待时长。重放归档实验标明原日期，不称为本次新增实验。

操作指南应与最终视频共用场景 ID/顺序，给出前置条件、确切命令、期望观察、
常见失败处理和收据保存位置。讲稿中的数值/术语与画面一致，缩写先转换成自然
口语，画面保留可查验的原字段。不要让字幕盖住证据。

## 声音选择与可用性

优先继承用户明确的语言、性别/音色、自然度、情绪和成本偏好。需要比较时使用
同一段含有项目专名、数字、单位与停顿的短文本；先试听，再生成全片。

供应商/模型/定价/访问规则可能变化，通过当前一手文档和实际账户能力核查。
可选服务只是候选，既往脚本、已安装客户端或列出声线不等于合成成功。
按实际情况记录以下状态：

| 状态 | 所需依据 |
| --- | --- |
| 文档已查 | 当前官方来源、日期、支持能力/费用/授权条件 |
| 可用性已测 | 实际调用结果，失败码或限制；不记录凭据 |
| 样音已生成 | 同文本样音、声线/配置、文件哈希与时长 |
| 已选用 | 用户选择或明确说明的代理判断及适用偏好 |
| 全片已生成 | 每段音频、文本、配置、版本、哈希与时长 |
| 已试听 | 实际试听范围、发音/自然度/停顿反馈及修订 |

凭据只通过安全环境注入。用户未授权的付费或外部数据传送按会话边界处理。
端点不可用时保留失败，不因文档可访问而声称生成成功；可以继续静态材料。

`check_narration.py` 接收完整音频文件，用 ffprobe 检查真实音频流与时长。默认
留 0.3 秒尾部余量，可通过 `--margin-seconds` 调整；场景可设 `lead_in_seconds`。
超时应精简口语、调整场景或换更合适的自然声线后重新生成，不能以截断或加速
消除超时。此检查不验证音频有没有读完文本，也不判定自然度。

保存最终录音，使离线播放不依赖将来还能访问在线服务。音量归一化等后处理可用，
记录处理参数及处理前后文件；不要据此声称未测试的声线更自然。

## 媒体验收

先生成关键帧/场景预览，检查终端字号、可视区域、标签、图意与字幕；再用最终
编码的视频进行完整解码检查，例如当前环境可执行 FFmpeg 时：

```sh
ffmpeg -v error -i <final-video.mp4> -f null -
```

使用 ffprobe 核对最终时长、分辨率、音视频流，按比赛要求判定。实际播放或
听取最终音轨，核对旁白完整性、发音、停顿、音量、每段同步与结尾。音量峰值
和响度测量可以补充听审，不能替代听审。没有播放/听取的部分写成未检查。

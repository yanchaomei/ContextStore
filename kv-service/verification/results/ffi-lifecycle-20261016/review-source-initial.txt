Important finding 1: close retains a dangling native handle if Python raises at native return.
Location: src/contextstore/storage/rdma_client.py:466-471.
close() clears _handle only after the ctypes free call returns normally. A blocking native free may finish destroying the Rust client, then ctypes surfaces a pending KeyboardInterrupt before the assignment clearing _handle executes. A later close() or __del__ retries free on the dangling pointer, creating a double-free/use-after-free path. Detach _handle into a local and set _handle=None / _connected=False under the lock before the free call. The provider failure path already aborts; retrying a freed pointer is never a safe recovery strategy. Regression: simulate native free completing and then raising BaseException, and confirm a second close does not call native free again. The pre-existing sequencing is now in the lifecycle-hardening scope.

Important finding 2: descriptor fields silently alias through ctypes narrowing, and C strings accept embedded NUL.
Locations: src/contextstore/storage/rdma_client.py:373-385 and 400-410; all key.encode(), descriptor handle/etag .encode() native arguments; constructor port/gid at 111-115.
ObjectDescriptor is a mutable dataclass without value validation (src/contextstore/kvservice_client/types.py:42-54). c_uint64/c_uint32 modulo conversion means generation=2**64+g aliases generation=g, size=2**64+n aliases size=n, and stripe_count=2**32+s aliases s. This can successfully read a different object identity than the caller supplied. Embedded NUL in key/handle/etag is truncated by the CStr ABI, silently aliasing another key/descriptor instead of rejecting invalid input. port/gid similarly wrap through c_uint8. Snapshot all descriptor fields once, validate the same snapshot before ctypes conversion, and reject invalid integer types/ranges, non-bool striping flag, non-string/NUL-containing/wire-overlength strings. Add tests proving invalid calls make no native transfer and preserve connection state. This behavior predates parts of the diff but remains a gap in the requested invalid-argument hardening.
